# Architecture Portfolio - Scroll Animation

A high-performance, smooth scroll-driven image sequence animation built with HTML5 Canvas and native JavaScript.

## Features
- **745 Frame Sequence**: Smooth playback through 745 high-resolution frames.
- **Inertial Lerp Smoothing**: Linear interpolation ensures wheel, touchpad, keyboard, and scrollbar drag gestures feel fluid without stutter.
- **Priority Preloading & Fallback**: Dynamic lookahead loading with zero blank-frame flicker.
- **Minimalist Aesthetic**: Full-viewport responsive display with zero UI clutter.

## Getting Started

Start the local server:
```bash
npm start
# or
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
